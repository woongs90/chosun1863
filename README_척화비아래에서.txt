「척화비 아래에서」 (한국사 · 개항기 1편: 흥선대원군 ~ 임오군란) — RPG Maker MV 프로젝트에 붙여넣기

1. RPG Maker MV에서 새 프로젝트를 만들고, 이 zip 안의 폴더들(data, img, audio, movies, js, fonts)을 프로젝트 폴더에 그대로 덮어써 붙여 넣으세요.
2. 게임을 실행하면 인트로 영상(건너뛸 수 없음) → 장 고르기(처음부터 · 1~5장 · 이어하기 번호)로 시작해요.
3. 선생님용 정답 · 해설 · 이어하기 번호 · 실제 사진 목록: docs/선생님용_정답과_해설_척화비.txt
4. 데이터 고치는 법(새 퍼즐 방식 포함): docs/데이터_작성법.txt
5. 그림 · 지도 · 음악 · 데이터를 다시 만드는 도구: tools_kr/k_build.py (python3 tools_kr/k_build.py <프로젝트 폴더>)
   글꼴: fonts/EscReadable-Medium.ttf (Noto Sans KR, OFL 무료 글꼴)
   지도 자료: historical-basemaps (Ourednik, GPL-3.0)
